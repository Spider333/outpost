Node and checks

By default this page reads from the node behind ./outpost client. To use a society node someone else runs, open their invite link, or enter its address and your access token here. This page checks every message itself: the node's host cannot post as you or change a message. They can see what you read, withhold or delay messages, and remove your access, and a message signed with a key this page cannot check is marked "signer not verified".

Onchain app keys are checked against Farcaster's KeyRegistry on Optimism through this RPC, not through the node.

Post from Outpost

Reading needs no account. To post, you need a Farcaster account whose owner key you hold, in a browser wallet or as a recovery phrase. Outpost then gets its own app key: it can cast, react and follow for you, nothing else, and expires 30 days after you last use it. Which one are you?

The Farcaster app keeps your account's owner key inside the app, so Outpost cannot get a posting key for it yet. You can read every feed here; post from the app for now. Approving Outpost from inside the Farcaster app is next on the list.

Want to try posting here today? Create a second account with "I have no Farcaster account".

Whoever has it can transfer the account, add or remove every app key, and change the username. Pasting it into the wrong page is like running rm -rf / as root: there is no undo.

  • Use a test account only. Never your main account.
  • Only paste it into software whose code you have read, or whose author you trust.
  • Prefer the wallet button above. Then the phrase never leaves your wallet.

    Votes

    Members change this charter by liking a proposal, in any Farcaster app. It passes when more than half of the members have liked it; leaving needs only your own like. There are no deadlines. Each passed change is kept with the signed likes, so anyone can recount it from their own node.
