Node and checks

By default this page reads from the node behind ./outpost client. To use a society node someone else runs, open their invite link, or enter its address and your access token here. This page checks every message itself: the node's host cannot post as you or change a message. They can see what you read, withhold or delay messages, and remove your access, and a message signed with a key this page cannot check is marked "signer not verified".

Onchain app keys are checked against Farcaster's KeyRegistry on Optimism through this RPC, not through the node.

Connect an account

To post, this client needs its own app key: a key that can cast, react and follow for your account, and nothing else. It expires 30 days after you last use it. Your account's owner key (the custody key) signs one authorization for it.

Stop. A recovery phrase is the master key of an account.

Whoever has it can transfer the account, add or remove every app key, and change the username. Pasting it into the wrong page is like running rm -rf / as root: there is no undo.

  • Use a test account only. Never your main account.
  • Only paste it into software whose code you have read, or whose author you trust.
  • Prefer the wallet button above. Then the phrase never leaves your wallet.

This page uses the phrase in your browser to sign one authorization, then drops it. It is never saved and never sent anywhere.
