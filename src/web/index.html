Connect to a node to start

Outpost is a Farcaster client that reads and posts only through a node you choose, and checks every message itself.

  1. Just looking? Read through Farcaster's public node, with no setup. You cannot post there: posting needs your own node or a society's.
  2. Got an invite link? Open it again and press Join.
  3. Have a server? Run ./outpost client there and open the address it prints.

Post from Outpost

Reading needs no account. To post, choose the one that fits you.

How does posting work?

You need a Farcaster account whose owner key you hold, in a browser wallet or as a recovery phrase. Outpost then gets its own app key: it can cast, react and follow for you, nothing else, and expires 30 days after you last use it.

The Farcaster app keeps your account's owner key inside the app, so Outpost cannot get a posting key for it yet. Read every feed here, and post from the app for now.

Approving Outpost from inside the Farcaster app is next on the list. Want to post here today? Create a second account with "I have no Farcaster account".

Stop. A recovery phrase is the master key of an account.

Whoever has it can transfer the account, add or remove every app key, and change the username. Pasting it into the wrong page is like running rm -rf / as root: there is no undo.

  • Use a test account only. Never your main account.
  • Only paste it into software whose code you have read, or whose author you trust.
  • Prefer the wallet button above. Then the phrase never leaves your wallet.

      Votes

      A change passes when more than half of the members like the proposal, in any Farcaster app.

      How are votes counted?

      Leaving needs only your own like. There are no deadlines. Each passed change is kept with the signed likes, so anyone can recount it from their own node.

          Propose a change

            Up to 10 changes. Posting casts the proposal from your account and likes it, which counts as your approval.

            Node and checks

            What can a society node's host do?

            By default this page reads from the node behind ./outpost client. To use a society node someone else runs, open their invite link, or enter its address and your access token here. This page checks every message itself: the host cannot post as you or change a message. The host can see what you read, withhold or delay messages, and remove your access. A message signed with a key this page cannot check is marked "signer not verified".

            App keys are checked against Farcaster's KeyRegistry on Optimism through this RPC, not through the node.
