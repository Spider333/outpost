# kit (working name)

Three commands from zero to your own client for Farcaster:

```
./kit provision   # rent a server by script
./kit node        # start a Snapchain read node, no API keys
./kit client      # run a client that reads from your node
```

Status: under construction. Not ready for testers yet.
